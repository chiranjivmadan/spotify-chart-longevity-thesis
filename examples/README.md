# Synthetic workflow illustration

Run from the repository root with `python examples/synthetic_workflow.py`. It uses six entirely invented toy tracks, no packages beyond Python's standard library, and writes no files.

The demonstration shows how appearances in weeks 1–4 define X, appearances in weeks 5–52 define Y52 even after a gap, and how a constant training-median benchmark is calculated using training tracks only for each toy fold. Its folds are **illustrative**, not the thesis's protected 276-component grouped folds. It does not execute or validate any thesis model, reproduce a thesis table, or provide empirical evidence.
